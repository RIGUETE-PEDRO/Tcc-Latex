\chapter[Problema de Pesquisa]{Problema de Pesquisa}

O setor de alimentação fora do lar exige rapidez, controle e organização. Em uma lanchonete, o atendimento envolve atividades como recebimento de pedidos, preparação, controle de itens consumidos, atualização do estoque e pagamento. Quando essas etapas não são apoiadas por um sistema integrado, aumentam as possibilidades de erros humanos, informações desencontradas, atrasos no atendimento e dificuldades no controle das operações.

No estabelecimento tomado como referência para este trabalho, identificou-se a necessidade de organizar processos relacionados a produtos, pedidos, comandas, usuários e relatórios. A execução manual dessas atividades pode ocasionar erros de anotação, dificuldade para localizar pedidos, demora no fechamento de contas e baixa visibilidade sobre os produtos com maior saída. Além disso, a ausência de um controle formal de acesso dificulta a separação de responsabilidades entre os diferentes usuários do sistema. A falta de um banco de dados centralizado também pode comprometer a confiabilidade das informações e o acompanhamento do estoque e das vendas.

Diante desse contexto, torna-se relevante investigar como uma aplicação web pode contribuir para a automação das rotinas internas de uma lanchonete. Para isso, este trabalho propõe o desenvolvimento de um sistema utilizando Laravel e MySQL, apoiado por tecnologias como PHP, Docker, MVC, RBAC e Git/GitHub, buscando oferecer uma solução adequada ao contexto de pequenos estabelecimentos.

Diante disso, este trabalho busca responder à seguinte questão de pesquisa:

\begin{quote}
\textbf{Como o desenvolvimento de um sistema informatizado utilizando Laravel e MySQL pode contribuir para a automação de processos e para a melhoria da gestão operacional de uma lanchonete?}
\end{quote}
